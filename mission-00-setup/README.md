# Mission 0 - Setup

## 1. Task / objective
Create a correctly named public GitHub repository and prepare a folder structure for all the missions of the Digital Detective assignment.

## 2. Work completed
- Checked that Python 3 and Git are installed.
- Created the project folder `digital-detective-8460`, matching the GitHub repository name.
- Created 9 mission folders (mission-00 to mission-08) and an `evidence` folder.
- Created a README.md in the root and in every mission folder, plus an empty `number_converter.py` in the Mission 5 folder.
- Wrote the root README with a mission index.
- Created a public GitHub repository with the same name and pushed the setup to it.

## 3. Commands / tools used
- `python3 --version`: shows the installed Python version (Python 3.14.7).
- `git --version`: shows the installed Git version (git 2.55.0).
- `mkdir`: creates folders.
- `cd`: moves into a folder.
- `pwd`: shows the full path of the current folder.
- `touch`: creates an empty file.
- `ls`: lists files and folders.
- `git init`: starts Git tracking in the project folder.
- `git add`: selects the files to include in the next commit.
- `git commit`: saves a checkpoint of the selected files.
- `git remote add origin`: connects the local project to the GitHub repository.
- `git push`: uploads the commits to GitHub.
- Tools: Terminal, a text editor, GitHub in the browser.

## 4. My understanding
A repository is a place where project files and their change history are stored. Mission folders keep each task's work organized and easy to find. A commit saves a checkpoint so that changes can be tracked and reviewed.
